# 🛠️ How to install

Installation only takes a minute.

### Google Chrome 🟢

1. ⬇️ Download the extension ZIP above.
2. 📂 Extract the ZIP file somewhere on your computer.
3. Open Chrome.
4. Enter `chrome://extensions` in the address bar.
5. Enable **Developer mode** in the top-right corner.
6. Click **Load unpacked**.
7. Select the extracted extension folder.
8. Open or refresh **RedGIFs.com**.
9. 🎉 Look for the small download icon on videos!

### Microsoft Edge 🔵

1. ⬇️ Download and extract the extension ZIP.
2. Open Microsoft Edge.
3. Enter `edge://extensions` in the address bar.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted extension folder.
7. Open or refresh RedGIFs.
8. 🎉 You're ready!
